# Handwritten Digit Recognition

A Python-based machine learning project that implements a **K-Nearest Neighbors (KNN)** classifier to recognize handwritten digits from the **MNIST dataset**.

## Overview

The project demonstrates:

* Data preparation and feature-target separation
* 80/20 train-test split
* Handwritten digit visualization
* Manual KNN implementation using Euclidean distance
* Digit prediction and comparison with the actual label

## Dataset

The project uses the **MNIST handwritten digit dataset** with 42,000 records, 784 pixel features, and one target column (`label`).

The `train.csv` file is not included in the repository due to its file size.

## Technologies

**Python · Pandas · NumPy · Matplotlib · Jupyter Notebook · KNN**

## How to Run

1. Download the `train.csv` dataset.
2. Place `train.csv` in the project folder.
3. Open `KNN_Digit_Recognizer.ipynb` in Jupyter Notebook or JupyterLab.
4. Run the cells in order.
